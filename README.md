# Личный сайт Создателя Уггла & Властелина Цифрового Мира

Официальный одностраничный портал-визитка для **GitHub Pages** с острым бруталистским дизайном (0% border-radius), переключателем тем, интерактивной командной строкой, синтезатором звуков и сатирой на всю IT-индустрию.

## Особенности и Функционал

- **100% Острый брутализм**: абсолютный 0% border-radius, чистые 90-градусные углы, контрастные тени и техническая сетка.
- **Мульти-темовость (4 темы)**:
  - ☀️ *Светлая* (чистый белый брутализм);
  - 🌙 *Ночная* (глубокий обсидиан);
  - 🟢 *Матрица* (терминальный неоновый зелёный);
  - 🟡 *Киберпанк* (высококонтрастный жёлто-бирюзовый).
- **VIP-Диспетчер звонков Кремниевой Долины**:
  - Быстрое переключение между 6 техно-титанами: *Дженсен Хуанг (NVIDIA)*, *Илон Маск (Tesla/SpaceX)*, *Павел Дуров (Telegram)*, *Сэм Альтман (OpenAI)*, *Линус Торвальдс (Linux)* и *Тим Кук (Apple)*.
  - Функции: отклонение вызова (счётчик растёт), постановка на удержание (таймер с фоновыми бипами), генератор саркастичных автоответов и переключение абонентов.
- **Интерактивный Саундборд разработчика**:
  - 6 звуковых эффектов на чистом **Web Audio API** (без внешних mp3/wav файлов, работает 100% офлайн): «Прод упал», «Git push --force», «Оффер от инвесторов», «Глоток кофе», «Выход из Vim» и «Звонок миллиардера».
  - Поддержка Mute-режима.
- **Квантовый комбайн «Уггл 3.0»**:
  - **Квантовый Поиск**: база из десятков остроумных ответов на запросы про IT, Vim, CSS, языки программирования и техногигантов.
  - **Калькулятор Зарплаты**: расчёт справедливой ставки сеньора на основе стека, опыта и умения выходить из Vim (с бонусами в виде шаурмы и освобождения от дейликов).
  - **Генератор Отмазок для Тимлида**: генерация отмазок на случай падения продакшена или просрочки дедлайна с кнопкой копирования в буфер обмена.
- **UGGL Shell (CLI-Терминал)**:
  - Полнофункциональная командная строка прямо на сайте (`help`, `matrix`, `coffee`, `skills`, `salary`, `fortune`, `ping`, `whoami`, `theme`, `clear`).
  - Пасхалка `sudo rm -rf /` с сиреной и анимацией тряски экрана.
- **Оффер-генератор v3.0**:
  - Проверка условий работы, расчёт вердикта и кнопка скачивания официального решения в формате `.txt`.
- **Полная адаптивность и независимость**: сайт статический, без npm/webpack, готов для мгновенного деплоя на **GitHub Pages**.

## Как запустить на GitHub Pages

1. Сделайте коммит и отправьте код в ваш репозиторий GitHub (`username.github.io`).
2. В настройках репозитория: `Settings` → `Pages` → выберите ветку `main` (или `master`) и папку `/ (root)`.
3. Готово!
