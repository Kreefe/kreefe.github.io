# Личный сайт Создателя Google & Кошмар Тима Кука

Официальный одностраничный сайт-визитка для **GitHub Pages** с белой темой и острым бруталистским дизайном (0% border-radius).

## Особенности

- **100% Острый дизайн**: строгие прямые углы (никаких скруглений), чёткие контрастные тени, чистая белая тема с технической сеткой.
- **Интерактивный поисковик Уггл**: генерация квантовых ответов на любые запросы.
- **Виджет входящего вызова от Тима Кука**: возможность отклонять звонки (счетчик пропущенных растёт) или ставить на бесконечное удержание.
- **Генератор офферов**: автоматический вердикт вашему предложению о работе.
- **Полная адаптивность**: идеально отображается как на 4K мониторах, так и на смартфонах.
- **Готов к GitHub Pages**: статический сайт без внешних сборок и зависимостей, с файлом `.nojekyll`.

## Как запустить на GitHub Pages

1. Сделайте коммит и отправьте код в ваш репозиторий GitHub (`username.github.io`).
2. В настройках репозитория: `Settings` → `Pages` → выберите ветку `main` (или `master`) и папку `/ (root)`.
3. Готово! Ваш сайт доступен всему миру.
